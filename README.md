# Smart Task Management System (TaskMaster Pro)

A high-performance task management application built with Flask and PostgreSQL, featuring real-time updates and data-driven analytics.

## 🚀 Key Features
- **RESTful API:** Full CRUD (Create, Read, Update, Delete) functionality for task management.
- **Real-Time Notifications:** Implemented using **WebSockets (Flask-SocketIO)** for instant UI updates across multiple clients.
- **Data Analytics:** Uses **Pandas and NumPy** to process task data and generate real-time completion statistics.
- **Relational Database:** **PostgreSQL** integration for persistent user and task data storage.
- **Authentication:** Secure user registration and login system with hashed passwords.

## 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **Database:** PostgreSQL
- **Data Processing:** Pandas, NumPy
- **Real-Time:** Socket.IO
- **Frontend:** HTML5, CSS3 (Bootstrap 5), JavaScript
